# NotionSnap 营销话术与产品定位

> 面向 Chrome Web Store 用户的产品营销文案体系

---

## 一、产品定位（一句话）

**NotionSnap** — 把任何网页一秒变成整洁的 Notion 笔记。

---

## 二、目标用户画像

### 核心用户
- **重度 Notion 用户**：用 Notion 做知识管理、阅读笔记、项目文档的人
- **信息工作者**：研究员、产品经理、工程师、内容创作者
- **中文内容消费者**：高频阅读公众号、知乎、小红书、Substack、Mirror 的用户

### 痛点场景
| 场景 | 痛点 | NotionSnap 解法 |
|------|------|----------------|
| 看到一篇好文章想保存 | 复制粘贴格式全乱，图片丢失 | 一键保存，格式完整，图片自动上传 |
| 微信公众号文章 | 链接过期、无法导出 | 专用解析器，完美保留富文本 |
| 用 Notion Web Clipper | 三天两头保存失败、空白页 | 稳定可靠，7 层降级保障 |
| 想分类存到不同数据库 | 手动搬来搬去 | 预设一键切换目标，自动字段匹配 |
| 保存后图片过几天就挂了 | 外链失效 | 后台自动上传到 Notion 托管，永不丢失 |

## 三、竞品对比

| 维度 | NotionSnap | Notion Web Clipper | Copy to Notion | Save to Notion |
|------|-----------|-------------------|----------------|----------------|
| 价格 | **免费开源** | 免费 | 付费订阅 | 免费 |
| 中文网站优化 | **公众号/知乎/小红书专用解析** | 无 | 无 | 无 |
| 图片上传 | **两阶段：秒存 + 后台替换** | 不稳定 | 支持 | 有限 |
| 多工作区 | **支持** | 支持 | 不支持 | 不支持 |
| 内容提取精度 | **7 个独立解析器 + 30+ 站点分类** | 通用 | 通用 | 通用 |
| 稳定性 | **3 层错误恢复 + SW 中断续传** | 经常失败 | 较好 | 一般 |
| 保存去重 | **URL 级别 5 秒去重** | 无 | 无 | 无 |
| 数据库字段映射 | **自动匹配 9 个元数据字段** | 不支持 | 支持 | 不支持 |
| 主题 | **双主题（暗色金属 + 黑白精准）** | 无 | 无 | 无 |

**核心差异**：NotionSnap 是唯一专为中文内容生态深度优化的免费 Notion 剪藏工具。

## 四、价值主张（USP）

### 对用户说

> **存得进去，找得回来。**
>
> 不像官方 Clipper 那样时不时罢工，不像 Copy to Notion 那样要付费订阅。NotionSnap 就是做了一个 Clipper 应该做好的事：把网页干净、完整地存进 Notion。公众号文章、Twitter 推文、GitHub Issue、Medium 博客——打开即存，格式不乱，图片不掉。

### 三个核心承诺

1. **秒级响应**。文字内容 < 1 秒落库，图片后台异步上传。你继续浏览，它默默完成。
2. **存得完整**。7 个网站专用解析器 + 30+ 站点智能适配。标题、作者、时间、正文、图片、代码块——一样不少。
3. **一直免费**。开源，无订阅，无隐藏收费。你的数据直接从浏览器到 Notion，不经过任何中间服务器。

## 八、品牌调性

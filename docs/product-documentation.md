# NotionSnap 产品文档

> 版本 v0.6.0 | 2026-05-27

## 概述

NotionSnap 是一款 Chrome 浏览器扩展，一键将任意网页保存到 Notion。它解决了 Notion 官方 Web Clipper 不稳定、Copy to Notion 付费的问题，提供免费、可靠、智能的网页剪藏体验。

核心能力：
- 从 30+ 类网站智能提取正文（公众号、Twitter、GitHub、Medium、Substack、知乎、小红书等）
- 一键保存到 Notion，自动识别页面/数据库
- 两阶段图片处理，秒级完成保存，后台异步上传
- 多工作区管理，预设快捷切换，保存历史回溯

## 安装

### Chrome Web Store（推荐）
*即将上架*

### 开发者模式安装
1. 下载最新版本 `NotionSnap-v0.6.0.zip`
2. 解压到任意目录
3. 打开 `chrome://extensions/`，开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的 `dist/` 目录

## 快速开始

### 1. 连接 Notion
点击扩展图标 -> 点击「连接到 Notion」-> 在 Notion 授权页面点击「允许」-> 自动返回弹窗。

### 2. 保存第一篇文章
打开任意网页 -> 点击扩展图标 -> 确认标题和内容预览 -> 选择目标页面 -> 点击「保存到 Notion」。

### 3. 快捷键保存
默认快捷键 `Ctrl+Shift+S`（Mac: `MacCtrl+Shift+S`），无需打开弹窗即可保存到最近使用的页面。可在 `chrome://extensions/shortcuts` 自定义。

### 4. 右键保存
在任意网页右键 ->「保存到 Notion」，直接保存到最近使用的页面。

## 功能详解

### 内容提取

NotionSnap 不是简单截取网页全文，而是**智能解析页面结构**，去除噪声，保留正文。

#### 独立解析器（7 个）

| 网站 | 提取内容 | 特殊处理 |
|------|---------|---------|
| **微信公众号** | 标题、作者、时间、正文、图片 | 50+ 噪声选择器（赞赏、评论、弹窗、底部引导），支持纯文字说说和图文说说 |
| **Twitter/X** | 推文文本、作者、时间、图片、视频 | 线程结构保持，推文间分隔线 |
| **GitHub** | README 渲染、Issue 标题/正文/状态/评论 | Markdown → Notion blocks，过滤 badge/avatar 噪声，代码块语言检测 |
| **知乎** | 问题描述 + 前 5 条回答 | 展开折叠内容，React 懒加载图片兼容 |
| **小红书** | 图片轮播、视频、笔记正文 | 评论和互动按钮噪声清理 |
| **Medium** | 标题、正文段落、作者、出版时间 | CTA/推荐/拍手/评论噪声清理，JSON-LD 元数据提取 |
| **Substack** | 标题、正文、作者、日期 | 订阅 CTA/付费墙噪声清理，自定义域名适配（如 zengzhang.ai） |

#### 通用提取（30+ 站点分类）

对未独立适配的网站，按域名分类匹配最优选择器和噪声规则：

- **博客类**：Hashnode、Dev.to、WordPress、简书、博客园
- **新闻类**：BBC、CNN、NYT、WSJ、路透社、彭博社、卫报
- **科技类**：TechCrunch、36Kr、少数派、The Verge、Ars Technica
- **加密类**：CoinDesk、BlockBeats、星球日报、Foresight、The Block
- **通用类**：自动识别 article/main/post-content 等标准语义标签

#### 内容保真

- **11 种 Notion block 类型**：段落、h1/h2/h3 标题、引用、无序/有序列表、代码块（自动语言检测）、分隔线、图片、视频、表格
- **富文本内联样式**：加粗、斜体、删除线、链接、内联代码、11 种文字颜色
- **图片智能提取**：兼容 6 种懒加载属性（data-src/data-original/data-lazy-src 等），URL 清理去参数
- **元数据提取**：作者、发布时间、摘要、网站名称、语言、封面图、字数统计

### 保存系统

#### 两阶段保存

**Phase 1 — 秒级落库**（< 1 秒）
文字内容 + 图片外部 URL 立即写入 Notion，用户可以马上在 Notion 中看到完整文章。

**Phase 2 — 后台替换**（异步，不影响使用）
扩展在后台逐个下载图片，上传到 Notion 服务器，替换外部 URL 为 Notion 托管链接。即使关闭弹窗、关闭浏览器，Service Worker 会在重启后自动恢复未完成的任务。

#### 保存去重
同一 URL 5 秒内重复点击只保存一次，防止手滑创建多条记录。

#### 错误恢复
- 网络错误自动重试 3 次（1s/2s/3s 退避）
- Notion API 限流（429）自动等待后重试
- Token 过期自动刷新，刷新失败发送系统通知

### 多工作区管理

连接多个 Notion 工作区，在弹窗底部一键切换。每个工作区独立存储：
- 最近保存的页面列表
- 预设（快捷保存目标）
- 保存历史
- 页面缓存

### 智能目标选择

#### 自动匹配
扩展自动学习你的使用习惯：
- 记住每个网页上次保存到了哪个页面/数据库
- 下次打开同一网站的页面，自动选中上次的目标
- 保存到数据库时自动加载 schema，按属性名/类型匹配 9 个元数据字段（URL、作者、发布时间、摘要、网站名称、语言、关键词、封面图、字数）

#### 预设
将常用保存目标设为预设，弹窗顶部显示彩色 pill 按钮，一键切换。最多 15 个预设。

#### 渐进式搜索
- 4 路独立请求并行加载页面列表，逐条即时渲染
- 搜索 300ms 防抖，缓存结果即时展示
- 滚动到底自动加载更多（上限 30 条）
- 保存过的目标永久保留，不受 Notion API 100 条限制

### 保存历史

弹窗内的历史面板（时钟图标）：
- 按日期分组显示所有保存记录
- 成功记录：一键在 Notion 中打开、复制链接
- 失败记录：保留提取数据，一键重试
- 最多 50 条记录

### 元数据编辑

保存前可展开「更多」面板，查看和编辑 9 个元数据字段。编辑后的值直接写入 Notion 页面或数据库属性。

### 主题

- **Raycast 主题**：暗色金属质感，紫红渐变，磨砂玻璃效果
- **Vercel 主题**：黑白精准风格，Geist 字体，1px 边框

主题切换实时生效，持久化保存。

## 图片处理

### 支持的图片场景
- 普通 `<img>` 标签
- 懒加载图片（data-src/data-original/data-lazy-src/data-actualsrc/data-url 等 6 种属性）
- `<picture>` 标签内的 `<source>`
- SVG 内嵌图片
- CSS 背景图（style 属性）

### 上传流程
1. 优先尝试 `external_url` 导入（让 Notion 服务器直接拉取，单次 API 调用）
2. 失败时 fallback 到二进制上传（扩展下载 → Notion S3）
3. CDN 防盗链图片保持外部 URL（Phase 2 会尝试替换）

### 限制
- 单张图片最大 5MB（Notion 免费层限制）
- 部分 CDN 防盗链图片无法上传，显示为占位链接

## 隐私与安全

- **数据不经过第三方服务器**：内容直接从浏览器发送到 Notion API
- **OAuth 标准认证**：不存储你的 Notion 密码
- **Token 本地存储**：access_token 存储在 Chrome 本地存储中，仅用于调用 Notion API
- **开源透明**：所有代码在 GitHub 公开，可审计
- **仅必要权限**：activeTab（当前标签页）、storage（本地存储）、scripting（内容提取）、notifications（保存通知）、contextMenus（右键菜单）

## 常见问题

### Q: 和 Notion 官方 Web Clipper 有什么区别？
A: 官方 Web Clipper 经常出现保存失败、内容丢失的问题。NotionSnap 专为中文内容优化（公众号、知乎、小红书），支持两阶段图片上传保证可靠性，且完全开源免费。

### Q: 为什么有些图片在 Notion 中显示不了？
A: 部分网站的 CDN 开启了防盗链，禁止外部程序访问图片。这种情况下图片会显示为占位链接。我们正在开发 CDN 代理方案来解决这个问题。

### Q: 支持保存到 Notion 数据库吗？
A: 支持。扩展会自动检测你的目标是数据库还是页面，保存到数据库时自动匹配字段。

### Q: 搜索结果里找不到我的页面？
A: Notion 公共 API 只返回 100 条结果。但你保存过的页面会被永久记住，不受此限制。可以尝试用页面标题精确搜索。

### Q: 怎么修改快捷键？
A: 打开 `chrome://extensions/shortcuts`，找到 NotionSnap，点击修改。

## 已知限制

- Notion 公共 API 搜索仅 100 条上限，无法获取全部页面列表
- 不支持微信视频号视频提取（封闭生态）
- 部分 CDN 防盗链图片无法上传
- 仅支持 Chrome 浏览器（Firefox/Edge 适配计划中）
- 代码块单段限制 2000 字符（Notion API 限制）
